## 📝 О проекте

**FemboyApp** - это музыкальный плеер с системой авторизации, созданный на Python с использованием CustomTkinter. Приложение отличается приятным дизайном в розовых тонах и поддержкой нескольких языков.

### ✨ Особенности

| Функция | Описание |
|---------|----------|
| 🎵 **Музыкальный плеер** | Поддержка MP3, WAV, OGG |
| 🔐 **Авторизация** | Регистрация, вход, "Запомнить меня" |
| 🌍 **Многоязычность** | 5 языков интерфейса |
| 🎨 **Стильный дизайн** | Розовая тема, анимации |
| ⛶ **Полноэкранный режим** | F11 для переключения |
| 🔊 **Регулировка громкости** | От 0% до 125% |
| 📋 **Плейлист** | Сохранение в JSON |
| 🖼️ **Аватарки** | Смена фото профиля |
| ⚙️ **Настройки** | Тема, язык, автовоспроизведение |

## 🚀 Установка

### Системные требования
- **OS:** Windows 10/11
- **Python:** 3.8 или выше
- **RAM:** 512 MB
- **Диск:** 100 MB свободного места

### Способ 1: Готовый EXE (рекомендуется)

1. Перейдите в раздел **[Releases](https://github.com/femboychiklove/femboychiklove.github.io/releases)** (это прямая ссылка на ваши релизы)
2. Скачайте `FemboyApp.exe`
3. Запустите файл

### Способ 2: Из исходного кода

```bash
# Клонируйте репозиторий
git clone https://github.com/femboychiklove/femboychiklove.github.io.git
cd femboychiklove.github.io

# Установите зависимости
pip install -r requirements.txt

# Запустите приложение
python main.py
